# Spring Boot Microservices with Kafka

A production-style microservices project built using Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL
- Redis
- Apache Kafka
- Docker
- Kubernetes
- Spring Cloud Gateway
- Eureka Server
- GitHub
- GitHub Actions (Coming Soon)
- GitHub Container Registry (GHCR) (Coming Soon)

---

## Microservices

- Auth Service
- Profile Service
- Order Service
- Email Service
- Analytics Service
- API Gateway

---

## Features

- JWT Authentication
- Role Based Authorization
- Event Driven Architecture using Kafka
- Redis Caching
- API Gateway
- Service Discovery using Eureka
- Kubernetes Deployment
- Dockerized Microservices
- Horizontal Scaling
- Load Balancing
- REST APIs

---

## Project Structure

```
Microservices Kafka

├── AnalyticsService
├── ApiGatewayService
├── AuthService
├── EmailService
├── OrderService
├── ProfileService
├── docker
├── k8s

```

```bash
docker-compose up --build
```
